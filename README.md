# urfu-30-days-tracker
# 🎓 Трекер первых 30 дней первокурсника

Интерактивное веб-приложение для помощи студентам первого курса в адаптации к университетской среде. Сервис предоставляет структурированный пошаговый чек-лист обязательных и полезных задач на первый месяц учёбы с интерактивным календарем, категоризацией и встроенными инструкциями.

## ✨ Основной функционал

* **Интерактивный чек-лист:** список ключевых задач на первые 30 дней с отметкой выполнения.
* **Календарь и трекинг прогресса:** визуальное отслеживание выполненных дел и расчёт общего прогресса в реальном времени.
* **Фильтрация по категориям:** быстрая сортировка задач по направлениям (*Документы*, *Учёба*, *Быт*, *Спорт*, *Люди*).
* **Контекстные подсказки:** модальные окна «Как это сделать?» с подробными инструкциями к каждой задаче.
* **Сохранение состояния:** использование `localStorage` — отмеченный прогресс сохраняется при закрытии страницы.

## 🛠 Стек технологий

* **Frontend:** HTML5, CSS3, Vanilla JavaScript.
* **Инфраструктура и DevOps:**
  * **Контейнеризация:** Docker (образ `nginx:alpine`), Docker Compose.
  * **CI/CD:** GitHub Actions (автоматическая валидация файлов и сборка Docker-образа).
  * **Хостинг:** GitHub Pages.
  * **Контроль версий:** Git Flow (`main`, `develop`).
